# Greyhaven Phone v2.10.1 — Realism & Native Social Profiles

Upgrade from v2.10.0. This package is **frontend-only**: do not reinstall the Wiro VPS relay or change keys, payment setup, or Nginx.

## Install

In the `extension-patch` folder of this archive, upload **all eight files** to the ROOT of the existing **3ld1n/Greyhaven-Phone** GitHub repository, replacing the existing files:

- `manifest.json`
- `entry.js`
- `entry.css`
- `image-gen.js`
- `image-gen-core.js`
- `image-gen.css`
- `social-studio.js`
- `social-studio.css`

**Do not delete** existing `index.js`, `loader.js`, `bridge.js`, `style.css`, etc. Do not upload the `extension-patch` *folder* as a subfolder. Only its contents go into the extension root.

Then in SillyTavern → Extensions → Manage Extensions → Greyhaven Phone → Update. Fully close and reopen the iPhone PWA to clear old JavaScript.

## Changes

1. No unconditional jewelry/accessory mentions in image generation. Accessories are sized only if explicitly present in metadata or Wardrobe.
2. Concise Seedream 4.5 photo prompts prioritize subject, pose, expression, authentic light, camera and skin, not elaborate backgrounds.
3. Image metadata generated by the text model now chooses a distinct camera mode: raw front camera, deliberate Snapchat-style filter, raw rear camera, or (when appropriate) professional photo. It keeps location to a small cue.
4. Instagram and Facebook have SEPARATE native pages inside the phone, no cross-app tabs or external popup. Profile includes counters, action buttons, grid/feed and top-right refresh (generates **one new text/metadata post**, not a paid Wiro image).
5. Owner post edit/delete retained. Instagram Follow/Following, DM button, and Facebook connect/message use Greyhaven Phone's existing social APIs.
6. OnlyFans Settings allows editing the **complete creator refresh system prompt**, saving it or restoring the original with Reset to default. JSON structure is needed to keep the downstream parser working.
7. Generated images/reference packs/previously persisted social posts remain intact. No backend files have changed.

## Testing

Run `bash run-tests.sh` on a development machine with Node.js. These are code/unit and regression tests, not an assertion of live iOS/browser/Wiro output quality. Try one inexpensive image manually before running many.

## Important

The photography changes are prompt-based preferences, not absolute guarantees of image generation fidelity. "Refresh" on a character profile creates photo metadata with the connected text model; a new paid Seedream image is only requested after pressing **Generate** on its image placeholder.
